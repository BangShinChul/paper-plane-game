# 종이비행기 멀리 날리기

정사각형 종이를 손가락으로 직접 접어 종이비행기를 만들고, 접은 모양의 공기역학대로 날려 거리를 겨루는 3D 웹 게임입니다. 빌드 과정 없이 `index.html` 파일 하나로 동작합니다.

## 실행

- `index.html`을 브라우저로 엽니다. 설치나 서버가 필요 없습니다.
- 3D 라이브러리(three.js r128)와 글꼴을 CDN에서 받으므로 인터넷 연결이 필요합니다.
- GitHub Pages로 올리려면 저장소 Settings → Pages에서 기본 브랜치의 루트를 지정하면 됩니다.

## 게임 진행

처음 화면에서 **시작하기**를 누르면 접기로 들어갑니다. 저장해 둔 비행기를 바로 불러올 수도 있고, 내 최고 기록과 간단한 방법 안내도 여기서 볼 수 있습니다.

1. **접기** — 종이의 한 점을 잡고 끌면 그 점이 손가락을 따라오며 접힙니다.
   - 되돌리기, 펼치기(접은 자국이 남음), 뒤집기
   - 잡은 겹만 접기 / 모든 겹 함께 접기
   - 모서리·중점·1/8 격자 스냅, 손가락에 가려지는 부분을 보여 주는 확대창
   - 두 손가락으로 종이 옮기기·확대, 안내판 접기, 화면 맞춤
   - 종이 꾸미기: 앞면·뒷면 색 12가지, 무늬 7가지, 랜덤 종이
   - 보관함: 접은 비행기를 이름을 붙여 저장하고 언제든 불러오기 (이 브라우저에 최대 30개)
   - 예시 접기: 다트, 글라이더
   - 공유: 보관함에서 지금 비행기를 짧은 코드나 링크(`#p=PP1-…`)로 복사하고, 받은 코드를 붙여넣어 불러오기
   - 추천 접기: 지금 종이 상태에 맞는 다음 단계(양쪽 모서리를 가운데로, 코를 아래로, 반으로 접기, 날개 접기)가 버튼과 종이 위 점으로 나타나고, 누르면 접히는 모습이 재생됩니다. 추천만 눌러도 다트와 글라이더가 완성됩니다
   - 도구 줄은 되돌리기, 뒤집기, 새 종이, 다음만 보이고 나머지는 "더보기"에 있습니다
   - 따라 접기: 노란 점을 잡고 빨간 고리까지 끌면 되는 단계별 안내 (다트, 글라이더). 처음 시작하면 다트 안내가 자동으로 열립니다
   - 대칭 접기: 한쪽을 접으면 반대쪽도 똑같이 접힘 (반으로 접은 뒤의 날개 접기 포함, 끌 수 있음)
   - 접는 과정 보기: 지금까지 접은 순서를 처음부터 애니메이션으로 재생
2. **자세히 조정 (선택)** — 날개 각도와 뒤끝 휨은 자동으로 맞춰집니다. 직접 바꾸고 싶으면 접기 화면의 더보기 → 자세히 조정에서 접은 곳마다 각도(0~180°)를 정합니다.
   - 비행기를 눌러 잡는 곳 지정
   - 왼쪽·오른쪽 날개 뒤끝 휘기 (위/아래)
   - 날개 면적, 앞뒤 안정성, 좌우 균형, 예상 활공비 표시
3. **날리기** — 옥상에서 비행기를 쥔 1인칭 화면입니다. 화면을 길게 눌렀다 떼거나(누르는 동안 힘이 오르내림), 아래로 당겼다가 위로 빠르게 밀어 던집니다.
   - 바람 방향과 풍속이 화면에 표시되고, 비행 중에도 몇 초마다 서서히 바뀝니다. 맞바람은 거의 불지 않습니다.
   - 착륙하면 거리·체공 시간이 나오고 리더보드(이 브라우저에만 저장)에 기록할 수 있습니다.

## 화면과 소리

- 그림자, 풀밭·물결·종이 질감, 날개 끝 자취, 충돌 충격파와 불꽃 입자, 속도에 따라 넓어지는 시야
- 바람 소리는 속도를 따라 커지고, 접기·던지기·충돌·착지·상승기류 등에 각각 효과음이 있습니다. 비행 중에는 잔잔한 선율이 흐릅니다.
- 50m마다 거리 알림이 뜨고, 자기 최고 기록을 넘으면 따로 알려 줍니다.
- 소리는 접기 화면과 던지기 화면의 "소리 켬/끔" 버튼으로 끌 수 있습니다.
- 기기가 느리면 그림자와 해상도를 자동으로 낮춥니다.
- 오른쪽 위 버튼으로 한국어와 영어를 바꿀 수 있습니다. 기본은 한국어이고 선택은 기억됩니다.

## 조작

| 동작 | 터치 | 키보드 |
|---|---|---|
| 접기 | 종이를 잡고 끌기 | 마우스 드래그 |
| 종이 옮기기·확대 | 두 손가락으로 끌기·벌리기 | 오른쪽 버튼 드래그, 휠 |
| 모양 돌려 보기 | 끌기 | 마우스 드래그, 휠 |
| 던지기 | 길게 눌렀다 떼기, 또는 아래로 당겼다가 위로 밀기 | 마우스로 같은 동작 |
| 비행 중 좌우·하강 | 화면을 누른 채 끌기 | WASD, 방향키 |
| 회피 구르기 | 회피 버튼 | Space |

비행 중에는 좌우와 아래로만 움직일 수 있습니다. 올라가는 방법은 군데군데 서 있는 상승기류 기둥(바닥의 노란 고리)과 외계인 광선뿐입니다.

## 비행 중 만나는 것들

| 이름 | 효과 | 대처 |
|---|---|---|
| 새 떼 | 속도가 줄고 크게 흔들림 | 아래로 내려가기 |
| 비둘기 똥 | 맞을 때마다 무거워짐 | 옆으로 계속 움직이기 |
| 여객기 | 뒷바람에 곤두박질 | 아래로 내려가기 |
| 영웅 | 충격파에 날려감 | 옆으로 비키기 |
| 먹구름 | 비에 젖어 무거워지고 번개를 맞음 | 비 기둥을 돌아가기 |
| 돌풍 | 옆으로 밀림 | 반대쪽으로 버티기 |
| 외계인 | 초록 광선이 위로 끌어올려 줌 (도움) | 광선 안에 머무르기 |

## 동작 원리

- **종이접기**: 종이를 볼록 다각형 조각들로 나누고, 접을 때마다 접는 선으로 조각을 자른 뒤 움직이는 쪽을 반사시킵니다. 각 접기에는 각도가 있어, 완전히 접힌 상태(180°)에서 덜 접힌 입체 모양을 만들 수 있습니다.
- **공기역학**: 접힌 모양에서 날개 면적, 날개 폭, 무게중심, 양력 중심, 좌우 비대칭, 정면 저항을 계산합니다. 비스듬히 세운 작은 면과 휜 뒤끝은 조종면으로 계산합니다.
- **비행**: 양력·항력·피칭·롤을 1/400초 이하 간격으로 적분합니다. 받음각이 실속각을 넘으면 양력이 꺾이고 항력이 크게 늘어납니다.
  - 무게중심이 양력 중심보다 **앞**에 있으면 안정적으로 납니다. 너무 앞이면 빠르게 내리꽂습니다.
  - 무게중심이 **뒤**에 있으면 고개를 들다 실속해 뚝 떨어지기를 반복하고, 많이 뒤면 거의 못 나갑니다.
  - 세게 던질수록 좋은 것은 아닙니다. 활공형은 너무 세게 던지면 솟구쳤다가 실속합니다.
- 실제 풍동 수준이 아닌 근사 모델입니다.

## 파일 구성

```
index.html                              종이비행기 게임
extras/ascii-monster-garden/index.html  글자로 그리는 3D 동산 탐험 게임
extras/ascii-abyss/index.html           글자로 그리는 쿼터뷰 액션 RPG
```

`extras`의 두 게임은 같은 작업 과정에서 만든 별개의 단일 파일 게임이며, 외부 라이브러리 없이 동작합니다.

## 사용한 것

- [three.js](https://threejs.org/) r128 (MIT)
- Google Fonts: Gaegu, IBM Plex Sans KR, JetBrains Mono, Gowun Batang

## 도전 과제와 비행 중 볼거리

- 도전 과제 16개: 처음 화면의 "도전 과제" 버튼에서 확인합니다 (거리, 체공 시간, 고리, 상승기류, 과녁 착륙, 직접 설계한 비행기 등). 달성 기록은 이 브라우저에 저장됩니다.
- 고리: 활공 경로 앞쪽에 노란 고리가 나타납니다. 통과하면 속도가 조금 붙습니다.
- 착륙 과녁: 땅 위의 과녁에 내려앉으면 +10 m, 한가운데면 +20 m 보너스.
- 하늘 분위기: 비행마다 낮, 노을, 흐림 중 하나가 정해집니다 (보기만 달라집니다).
- 비행 궤적: 결과 화면에 거리와 높이 그래프가 나오고, 고리·충돌·상승기류 지점이 점으로 표시됩니다.

## 잠시 멈춤

비행 중 오른쪽 위의 Ⅱ 버튼(또는 P / Esc 키)으로 멈춥니다. 다른 탭이나 앱으로 넘어가면 자동으로 멈추고, 멈춘 화면에서 계속하기, 다시 던지기, 처음 화면을 고를 수 있습니다.

## 종이 모양

"종이 고르기"에서 정사각형, A4 세로, A4 가로, 원형 중 하나를 고릅니다. 모양을 바꾸면 새 종이로 시작하고, 종이 넓이에 따라 무게도 달라집니다 (A4는 정사각형의 약 1.4배, 원형은 약 0.8배). 따라 접기와 예시는 정사각형 종이로 진행하며, 보관함과 공유 코드에는 종이 모양도 함께 저장됩니다.

## 방해꾼과 난이도

새 떼, 영웅, 비둘기는 정면 멀리에서 다가오므로 미리 보고 피할 수 있습니다. 250 m마다 방해 단계가 올라가 방해꾼 간격이 짧아지고, 새 떼가 커지고, 비둘기가 더 오래 따라옵니다. 500 m부터는 영웅이 2명, 1000 m부터는 3명이 시간차를 두고 날아옵니다.

## 단순해진 흐름

단계는 접기 → 날리기 둘입니다. 접는 동안 안내판에 "예상: 잘 날 것 같아요 · 빠른 다트형"처럼 지금 접은 모양이 어떻게 날지 한 줄로 나오고, "날리러 가기"를 누르면 날개 각도와 뒤끝 휨이 자동으로 맞춰진 채 바로 던지기 화면으로 갑니다. 자세히 조정에서 손으로 바꾼 값은 그대로 유지됩니다.

## 그래픽

풍경은 구역마다 하나의 메시로 합치되 각 도형의 부드러운 법선을 그대로 유지해 둥근 면이 매끈하게 보입니다. 나무는 층층이 쌓인 침엽수와 잎 덩어리 활엽수, 집은 박공지붕·창틀·문·굴뚝, 구름은 둥근 덩어리, 먼 산은 울퉁불퉁한 능선과 눈 덮인 봉우리로 그립니다. 종이비행기는 은은한 광택과 종이 결, 날개와 몸통이 만나는 곳의 부드러운 그늘을 넣었습니다.

가까운 구역(앞 150 m, 뒤 100 m)은 촘촘한 도형으로, 먼 구역은 성긴 도형으로 그리고, 기기가 느리면 전부 성긴 도형으로 내립니다. 구름은 부드럽게 번지는 그림 스프라이트이고, 손은 손가락마다 곡선을 따라가는 매끈한 튜브로 만듭니다.

## 비행 중 즐길 거리

- 별과 부스트: 활공 경로 근처에 별이 세 개씩 나타납니다. 다섯 개를 모으면 부스트 버튼(키보드 E 또는 왼쪽 Shift)이 켜지고, 누르면 속도가 붙으며 살짝 떠오릅니다.
- 아슬아슬 보너스: 새나 새똥, 영웅을 스치듯 피하면 속도가 조금 붙고 별 하나를 얻습니다.
- 최고 기록 깃발: 가장 멀리 날았던 착륙 지점에 깃발이 섭니다.
- 꼬리 효과: 반짝이, 꽃잎, 비눗방울, 눈송이, 불꽃, 무지개, 번개, 황금 가루. 성능에는 영향이 없는 꾸미기이고, 각각 정해진 도전 과제를 달성하면 열립니다. 던지기 화면 아래의 "효과" 버튼에서 고릅니다.
- 메달: 결과 화면에 동(50 m), 은(120 m), 금(250 m), 다이아(400 m) 메달과 다음 메달까지 남은 거리가 나옵니다.
- 도전장: 결과 화면의 "도전장 보내기"로 내 비행기와 기록이 담긴 링크를 보냅니다. 받은 사람은 같은 비행기로 그 기록에 도전하고, 코스에 도전 깃발이 섭니다.
- 진동: 충돌, 별, 부스트에 짧은 진동이 울립니다 (지원하는 기기에서).
